実装との対応
  • 画面の枠（ヘッダー・トップタブ）は .mock-header／.mock-tabs で再現したモック専用要素です。 実装では OOTB Stock Header と Header Menu（src/fluent/sp-instance-menu/menu.now.ts の5タブ）が描画します。
  • <div class="sks-inquiry"> 以下がウィジェットの描画範囲で、 template.html と同一の DOM 構造・class 名・文言です。分岐は <!-- ng-if="..." --> の形でコメント併記しています。
  • スタイルは assets/sc-10-mock.css に集約しています。 前半は Bootstrap 3 相当の最小サブセット、後半が styles.scss 相当で、 SCSS変数（$brand-primary／$text-muted／$table-bg-accent／$font-size-small）は Bootstrap 3 の既定値で解決しています。実際の色はポータルテーマ（OOTB Coral）により変わります。
  • アイコンは実装では Font Awesome（<i class="fa fa-comments-o">）ですが、 モックは外部CSSを読み込まないためインラインSVGで代替しています。
  • 表示データは検証環境のデモデータに沿えています（事業者：株式会社テスト／起票者：事業 太郎）。 「申請書類の記載方法について（回答済）」は回答表示を確認するための追加データで、実インスタンスには未登録です。
未反映・確認事項
  • 件数上限の明示：max_records=30 を超える場合のみ <div class="panel-footer sks-truncated"> が表示されます。 ①のファイル内にコメントとして markup を残しています。
  • 参照範囲（Q05 未決）：ウィジェットオプション scope は self（自身が起票した問合せのみ）で配置済みです。 entity（同一事業者の問合せ）へ切り替える場合、履歴に他ユーザの問合せが並ぶため、起票者列の追加要否を検討してください。
  • やり取りの継続（SC-10 ⑥ 未確定）：現在は「1問合せ＝1回答」の単一回答モデルです。 複数往復を認める場合は⑤の回答ブロックをスレッド表示に変更する必要があります。
