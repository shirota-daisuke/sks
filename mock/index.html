別冊
  • 付録：画面番号未定の実装済み画面 — 本一覧と同じ「実装の写し」ですが、画面設計書に画面番号が無いため分けています。 現在は「申請の入力」（x_dent2_dentsusoke_apply）の3ファイルを収録。 画面設計書への追番が必要です。
  • ITCOM 担当範囲（申請機能・審査プロセス） — 処理No.16 以降の申請系・審査プロセスは ITCOM 主担当の範囲で未実装です。 その部分の画面イメージをまとめています（ITCOM-01〜09）。 実装が存在しないため設計提案です（画面番号も仮番号 ITCOM-nn）。
実装との対応
  • 画面の枠（ヘッダー・トップタブ）は .mock-header／.mock-tabs のモック専用要素です。 実装では OOTB Stock Header と Header Menu（src/fluent/sp-instance-menu/menu.now.ts の5タブ）が描画します。 未ログイン画面（SC-00〜SC-04）はタブを表示しません。
  • <div class="sks-*"> 以下がウィジェットの描画範囲で、template.html と同一の DOM 構造・class 名・文言です。分岐は <!-- ng-if="..." --> の形でコメント併記しています。
  • スタイルは assets/sks-mock.css（SC-00〜SC-09）に集約しています。前半は Bootstrap 3 相当の最小サブセット、 後半が各ウィジェットの styles.scss 相当で、SCSS変数はBootstrap 3の既定値で解決しています。 実際の色はポータルテーマ（OOTB Coral）により変わります。SC-10 は SC-10/assets/sc-10-mock.css に同等の内容を持っています。
  • アイコンは実装では Font Awesome（<i class="fa fa-*">）ですが、モックは外部CSSを読み込まないため インラインSVGで代替しています。
  • ★印のファイルは、実装では排他表示となる複数状態をレビュー用に1ファイルへ並べたものです。
  • 表示データは検証環境のデモデータに沿えています（事業者：株式会社テスト／ユーザ：事業 太郎（sks.demo）／ 申請：APP-2026-00123）。SC-06・SC-07 の一部、SC-10 の回答済データは状態を確認するための追加データで、実インスタンスには未登録です。 申請 APP-2026-00123 も手置きのデモデータだったため削除しました（申請の入力画面 ITCOM-01〜03 の実装により、 事業者が自分で申請を作成できるようになったため）。モックの表示値はそのまま残しています。
モック作成時に反映した実装課題（単体テスト結果より）
  • SC-04 STEP1（No.41・NG軽微）：メール形式不正時にエラーメッセージが表示されない。 sc-04-01-step1.html のコメントに修正案（help-block の追加）を記載。
  • SC-06 事業者情報（No.65・NG軽微）：必須未入力時にエラーメッセージが表示されない。 sc-06-02-entity-edit.html のコメントに修正案を記載。
  • SC-05 ロール不足時のアクセス（No.59・保留）：admin は 404 にならずページが開く可能性がある。 その場合の表示を sc-05-03-not-applicant.html に用意。
  • お知らせ read ACL の不正値（権限No.9・NG重要）：画面表示（ウィジェットの GlideRecord 経由）には 影響しないため、モックの内容には反映していません。ACL 側の修正が必要です。
